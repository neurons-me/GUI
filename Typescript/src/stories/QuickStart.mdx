# Quick Start

## 1. Install

```bash
npx this.gui my-app
cd my-app
npm install
npm run dev
```

That scaffolds a Vite + React app already wired to `this.gui` and `this.me` —
`AppShell` (left rail with navigation and the Theme, `.me` and Dev Tools
launchers, plus a top bar that says where you are), and a session surface, all
out of the box. `npm run dev` also starts (or reuses) a real `this.me` monad for
the app's own namespace via `npx monads start <app-id> --namespace
<app-id>.local` — nothing to provision by hand.

Prefer no build step? `npx this.gui --html` drops a single `index.html` that
loads `this.gui.umd.js` from a CDN and calls `window.GUI.mount(spec,
'#root')` directly.

## 2. What you get

```
my-app/
  src/
    app.ts        # declareApp(): id, namespace, title, theme, views
    main.tsx       # creates the public `me`, the runtime, mounts <Root/>
    Root.tsx       # <AppShell app={app} me={me} runtime={runtime} position brand .../>
    views/
      Home.tsx     # your first view: .GUI / Powered by .me / Get started
      Spaces.tsx   # Admin: the Spaces explorer, gated on a session
```

`app.ts` declares the shape; `main.tsx` wires it to a live `.me` connection;
every view is a normal React component that reads/writes through hooks like
`useSessionSurface()` and `useMeAction()` — no separate templating language
to learn on top of React.

## 3. The exports, by entry point

`this.gui` ships as several separate entry points — import only what a given
file needs, not the whole library:

- **`this.gui`** — `GUI.mount(spec, target)`, the bare runtime with no build
  step (used by `--html` mode)
- **`this.gui/runtime`** — `mountApp`, `declareApp`, `AppShell`,
  `SpecBoundary`, `createWsMeRuntime`, `AppDeclaration` — the app shell and
  the spec-to-React renderer
- **`this.gui/react`** — `SeedSessionProvider`, `SessionSurface`,
  `useSessionSurface`, `MeLauncher`, `CleakerLanding`, `useMe`, `useMeValue`,
  `useMeAction` — session and live-data hooks
- **`this.gui/atoms`** — `Box`, `Typography`, `Button`, `Card`, `TextField`,
  `Switch`, `Avatar`, `Chip`, … the base component set (see **Atoms** in the
  sidebar for the full list)
- **`this.gui/molecules`** — composite components built from atoms (see
  **Molecules**)
- **`this.gui/compounds`** — higher-level, app-shaped components (see
  **Compounds**)
- **`this.gui/devtools`** — `DevToolsLauncher`, `RuntimeInspector`,
  `SelectionProvider` — the inspector/selection overlay, opt-in
- **`this.gui/cleaker`** — the Cleaker identity/namespace surface pieces
- **`this.gui/style.css`** — base styles, import once at the app root

A minimal `main.tsx` touches three of these:

```tsx
import { createWsMeRuntime } from 'this.gui/runtime';
import { SeedSessionProvider, SessionSurface } from 'this.gui/react';
import 'this.gui/style.css';
```
