# Runtime

`this.gui` renders a spec, but **runtime** decides how data and actions resolve.

Modern usage is split across two explicit surfaces:

- `this.gui/react` for the `.me` React bridge
- `this.gui/runtime` for `mount()`, adapters, and lower-level runtime APIs

If you call `mount()` directly inside a React/Vite app, pass `gui`, `React`, and `ReactDOM` explicitly.

---

## Minimal: no runtime

Use this when you only need static UI.

```ts
import * as React from 'react';
import * as ReactDOM from 'react-dom/client';
import * as GUI from 'this.gui';
import { mount } from 'this.gui/runtime';

const spec = {
  type: 'Page',
  props: { title: 'Hello GUI' },
  children: [
    { type: 'Button', props: { variant: 'contained', children: 'Click' } },
  ],
};

mount(spec, '#root', { gui: GUI, React, ReactDOM });
```

---

## Pass a runtime adapter

Use this when you already have a runtime (custom adapter, router, shared app state).

```ts
import * as React from 'react';
import * as ReactDOM from 'react-dom/client';
import * as GUI from 'this.gui';
import { mount } from 'this.gui/runtime';

const runtime = buildRuntime(/* ... */);

mount(spec, '#root', { gui: GUI, React, ReactDOM, runtime });
```

---

## Pass a `.me` instance

If `.me` is your runtime, you can pass `{ me }` and GUI will derive the runtime.
For mixed React + mounted-spec screens, sharing an explicit runtime is cleaner.

```ts
import * as React from 'react';
import * as ReactDOM from 'react-dom/client';
import * as GUI from 'this.gui';
import ME from 'this.me';
import { createMeRuntime, mount } from 'this.gui/runtime';

const me = new ME();
const runtime = createMeRuntime(me);

mount(spec, '#root', {
  gui: GUI,
  React,
  ReactDOM,
  me,
  runtime,
  devtools: {
    inspector: false,
    inspectorToggleVisible: true,
    adminView: false,
  },
});
```

---

## When to choose which

- **No runtime**: static docs, marketing pages, or mockups.
- **runtime**: you already have a runtime adapter (router, app state).
- **me**: your app is driven by `.me` and you want the cleanest API.
